# 🎬 Movie Search App
🔗 Live Demo: https://movie-search-system.netlify.app/

## 1. Overview

This is a movie browsing and search application built using React. It allows users to explore popular movies, search for specific titles, and manage their favourite movies through a clean and responsive interface.

The application fetches real-time movie data from the TMDB API for displaying popular movies & the search functionality.

## 2. Core Features

* Browse popular movies
* Search movies using external API
* Responsive movie grid layout
* Add & manage favourite movies



### 3. Enhancements & Improvements

* Skeleton loaders introduced for better loading experience       
* INtegration of debounced search suggestions dropdown
* Clear button functionality added in search input
* Pagination ("Load more" functionality)
* Conditional rendering (search vs browse mode)
* Added Movie ratings with improved UI styles for cards
* Description overlay added for better content visibility
* Null checks & error handling introduced for safer data handling 
* Reusable component structure across the application
* Refactored project structure using constants & environment variables
* Customised API integration as per application needs



## 4. Tech Stack Used

* React
* JavaScript (ES6+)
* HTML & CSS
* TMDB API
